Full stack role on a product that helps users manage healthcare-related payments through a wallet-like experience. The codebase was React and Next.js on the front end, with a Java back end.

I shipped primarily in the UI, and also picked up back-end tickets — fixes and unit tests written with Mockito — when the work called for it.

Because the user base included older adults, accessibility was a real part of how we built features. We were intentional about semantic HTML, screen reader behaviour, and keeping flows simple and understandable.
